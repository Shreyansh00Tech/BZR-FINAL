# Blue Zone Residency (bzr.co.in)

Static marketing site for Blue Zone Residency, Noida. No build step.

## Files
- `index.html` – page, SEO tags, structured data
- `style.css` – styles
- `main.js` – interactions and enquiry form (Web3Forms)
- `*.webp`, `og-image.jpg`, favicons – images
- `vercel.json`, `robots.txt`, `sitemap.xml` – hosting and SEO

## Deploy
Pushing to `main` auto-deploys on Vercel.
